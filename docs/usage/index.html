Usage & commands

A full-screen TUI on a TTY, a plain ANSI REPL otherwise. --plain forces the REPL.

Starting

lugent [--plain] [--db path]

Piped stdin (non-TTY) falls back to the plain REPL automatically, so lugent is scriptable.

Slash commands

/model
Two-level picker: provider, then live model list. Pinned to the session.
/agent
Agent picker. Prompt, model and toolset apply from the next turn.
/skills
Browse loaded skills, read-only.
/mcp
Servers with status. Reconnect, disable, enable, authenticate, logout.
/resume
Pick a past session of this directory and continue it.
/permissions
Toggle normal or yolo.
/clear
Start a fresh session.
/exit
Quit.

Typing / in the composer opens an autocomplete box: it filters as you type, arrows move, Enter or Tab completes.

Keys

Ctrl+C ×1
Abort the running turn and deny a pending permission.
Ctrl+C ×2
Exit.
PageUp / PageDown
Page the live frame, or Shift+↑/↓.
Home / End
Jump to the top or tail of the live frame.
Esc
Stop a provider retry loop.

Finished turns land in the terminal's own scrollback, so the mouse wheel, touchpad and click-drag selection work natively.

Tools

read
allow. File with numbered lines, or a directory listing.
glob
allow. Glob file search, limit 100.
grep
allow. Content search, regex or literal.
edit
ask. Unique-match string replace, returns a diff.
write
ask. Create or replace a file.
shell
ask. bash, or cmd on Windows. Two minute default timeout.
skill
allow. Load a skill body by id.
subagent
ask. Launch a subagent in a child session.
