# Provider (SSE)

**SSE fragment accumulation.** Streaming `delta.tool_calls` arrive name-first then arguments in arbitrary chunk splits. Provider accumulates by `index` and concatenates `arguments` before parsing. Malformed JSON arguments stay a raw string — the loop's `validateArgs` turns them into a schema-error tool result so the model can retry, instead of crashing the turn. Events are yielded as they arrive (`parseSSE` is an async generator), so `onToken`/`onReasoning` fire during the stream — never buffered until the end.

**Provider.** `stream: true` always; retries **indefinitely** with exponential backoff (starts at 10s, doubles, caps at 60s) and an `onRetry` callback so UIs can show every failed attempt live; backoff sleep aborts immediately on the turn's `AbortSignal` (ESC stops the loop), and `maxRetries`/`backoffBaseMs` bound it for tests. Client errors (4xx other than `429`) are fatal — a bad key must not retry forever. Errors that used to vanish now surface: mid-stream SSE `error` events throw, a 200 with a `application/json` body (gateway error instead of a stream) throws its `error.message`, and the final failure reads `HTTP 503 (after N attempts)`. Streams are triply guarded — no response headers within 15s (`headerTimeoutMs`) aborts a dead host that accepts and never answers, no bytes for 120s (`idleTimeoutMs`) aborts the read with `stream stalled`, and a total wall-clock cap (default 10min, `totalTimeoutMs`) ends streams that drip keep-alive bytes forever (every byte resets the idle guard, only the total cap catches a proxy that pings without ever finishing); all surface as provider errors instead of forever-hung turns. Retryable failure bodies are cancelled before the retry fires (no socket leak per attempt). `GET /models` doubles as health check. Works with any OpenAI-compatible `/v1` endpoint.

**Model discovery (`discoverModels`).** The `/add-provider` form's Test action uses its own function, not `listModels()`. Three reasons it is separate: it is **bounded** (`AbortSignal.timeout`, 10s default) so a host that accepts and never answers cannot hang the overlay; it **never throws** — it returns `{ ok, models, error, noModels? }`, because a render path has nowhere to put an exception; and it resolves `{env:VAR}` through `subEnv()` the same way `loadConfig` does, so a reference to an unset variable is reported as `environment variable NAME is not set` instead of sending an unauthenticated request and blaming the server's `401`. `ok` requires a `2xx` **and** at least one parsed model id: a `200 {"data":[]}` **or a body that does not parse as JSON at all** (a login page, a wrong path, a proxy error page) is "endpoint answered but advertised no models", which keeps the import locked — but it sets `noModels`, which tells the form this is a reachable provider with nothing to import rather than a failed Test, so it offers to save the provider without a `models` key (spec decision 6). The line the branch keeps is **`2xx` vs not**: a `401`/`404`/`5xx` stays a hard failure with no `noModels`, because there is nothing to save against an endpoint that refused. An unparsable `2xx` body is deliberately indistinguishable from an empty list — the form cannot tell a login page from a gateway with no models, and decision 6 chose the recoverable reading. `listModels()` stays unbounded and throwing for the turn path — changing it would shift behavior for hand-written configs, which is its own change. Trailing slashes on `baseUrl` are stripped here (so Test never builds `//models`) and again in `saveProvider` (so a passing Test cannot be followed by a config whose every later chat 404s).

**The live-session entry is resolved, the file is not.** `saveProvider` returns `{ ok, error?, live }`; `live` is what the two front ends push into `env.config.providers[name]`, and its `apiKey` has already gone through `subEnv()`. This exists because `Provider.headers()` sends `cfg.apiKey` **verbatim** — it never substitutes — which is safe only for entries that came out of `loadConfig`. The form is the first writer of a raw typed key into that object, so pushing the typed string would send a literal `Bearer {env:VAR}` on every turn until restart: Test passes, the file is correct, and the session 401s. A reference that resolves to nothing is omitted from `live` entirely rather than becoming an empty `Bearer`. The file keeps the reference, unchanged.
