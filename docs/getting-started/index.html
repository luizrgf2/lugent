Getting started

lugent is a coding agent that runs in your terminal. One binary, one SQLite file, any OpenAI-compatible endpoint.

Install

The package ships unbuilt TypeScript under a bun shebang, so installing it does not run a build step. You need Bun 1.4 or newer on your PATH.

npm i -g lugent
bunx lugent   # without installing

Configure a provider

lugent talks to any OpenAI-compatible endpoint. Point it at one in ~/.config/lugent/config.json, or lugent.json in the project, which wins.

{
  "providers": {
    "ollama": { "baseUrl": "http://localhost:11434/v1" }
  },
  "defaultProvider": "ollama",
  "defaultModel": "qwen3.5:14b"
}

At startup each provider gets a health check. Unreachable ones report OFF, and lugent still starts.

What is in the box

  • Eight tools: read, glob, grep, edit, write, shell, skill, subagent
  • Agents, subagents and skills as markdown files in a folder
  • MCP servers over stdio or streamable HTTP, with OAuth
  • Sessions, messages and permission grants in one SQLite file
