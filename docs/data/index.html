Data & storage

One SQLite file holds sessions, messages and permission grants. Nothing leaves your machine.

Where the data lives

linux
~/.local/share/lugent/db.sqlite
windows
%APPDATA%\lugent\db.sqlite

$XDG_DATA_HOME is honoured on Linux when set. --db <path> overrides the location for a single run.

Other files

config.json
Global config: providers, defaults, permissionMode.
mcp-oauth.json
MCP OAuth tokens, mode 0600, keyed by the URL that issued them.
lugent.json
Project config, in the repo. Never put a secret in it.

Backup and cleanup

The database is a plain SQLite file. Copy it to back up every session, delete it to start clean. Deleting it also clears the permission grants.
